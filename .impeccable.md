## Design Context

### Users
Potential employers and clients: recruiters evaluating a full-stack / backend developer, and businesses with a process (Excel, WhatsApp, disconnected systems) they want turned into software. Viewed in a professional context; the page has to support both paths ("Busco talento" / "Tengo un proyecto").

### Brand Personality
Precise, curious, systems-minded. Confident and calm rather than flashy: the space metaphor (planets, orbits, layers) carries the idea "I see a system, not a screen".

### Aesthetic Direction
**Portfolio Espacial**: a deep night sky (`#030014`) with violet nebulae, a star canvas, shaded planets and orbit diagrams. Every token lives on `.space` in `src/styles/space.css`; `tailwind.config.mjs` only mirrors them.

- **Theme**: dark only
- **Colors**: bg `#030014`, ink `#EEEBFF`, soft `#C9C4EA`, dim `#A49FC9`, violet `#A78BFA` (primary accent), cyan `#7DE3FF` (focus, active, "after" states), amber `#FFC07A`, pink `#F9A8D4`, green `#6EF3A5` (current / available)
- **Fonts** (space type, 2026-10-09, user's choice): Exo 2 (`--display`/`--sans`: titles incl. the MARIO YAEL name, body), Orbitron (`--label`: short uppercase labels, eyebrows, stages, layer codes, planet numbers, the specialty band, footer wordmark/titles, contact title) and Space Mono (`--mono`: code editor, tech chips, dates, data). Earlier: Geist / Geist Mono; Audiowide + Oxanium in contact/footer.
- **Shapes**: panels at 16–20px radius, pill buttons, hairline violet borders (`--line`, `--line-soft`)
- **Motion**: `--ease: cubic-bezier(0.2, 0.8, 0.2, 1)`; pointer spotlight on panels; Lenis smooth scroll, all of it off under reduced motion

### Protected designs
Do not redesign these without asking: the MARIO YAEL heading (`Name.tsx`), the Hero (orrery, corner ribbon) and Proceso (`Process.tsx` + `SpaceRoute.tsx`, the space route with planets and a rocket, redesigned at the user's request on 2026-10-09).

### Home page structure (trimmed 2026-10-09)
Hero (orrery + faint Background Beams; primary CTA "Ver proyectos", a quiet recruiter line with experience/CV links) → Quick stats (3: years, demos, place) → Audience (2 doors) → Featured projects → Specialty band (scroll-linked) → Experience (developer editor + editorial list with milestones) → About → What I can build (5 capabilities; `#build` and `#before-after` are anchor aliases here) → Process (space route: planets + rocket, `SpaceRoute.tsx`) → Expertise (5 areas; `#system` alias) → Final CTA (lamp) → Contact form (Netlify Forms "contact"; `#configurator` alias).
- Removed at the user's request (2026-10-09): the configurator ("Cuéntame cómo trabajas") and the system layers ("No veo una pantalla. Veo un sistema."). The prefill event Solutions uses lives in `src/lib/prefill.ts`.
- Removed as repeated content (2026-10-09): the examples marquee and the before/after section; the stack shown in stats and the band; the /work case-study route (no project had a case study).
- Every card uses the About photo's Comet Card effect (`TiltCard` = `CometCard`); not on forms, the process panel or moving elements.
- Sections live in `src/components/sections/`, shared pieces in `src/components/kit/`, Aceternity adaptations in `src/components/aceternity/`, styles in `src/styles/v2.css`, copy in `src/data/v2.ts`.
- Aceternity is a tool, not the identity: night palette, hairlines, one accent at a time; every loop pauses off screen and under reduced motion; no content hidden server-side by an animation.
- Project screenshots: originals in `assets/projects/<project>/`, `npm run images` writes AVIF/WebP sizes to `public/projects/` and `src/data/project-images.json`; projects list them in `images` (src/content/projects).
- No visible section numbering (user removed it). Hero orbits carry no text labels.

### Design Principles
1. **Systems over screens**: diagrams (data flows, layers, before/after) explain the work better than adjectives
2. **Vary the rhythm**: not every section is heading + card grid; use editorial lists, split layouts and sticky headings
3. **Token discipline**: colors via the `.space` custom properties, never raw values in components
4. **Restraint in motion**: motion signals state or guides attention; nothing loops for decoration alone
5. **Bilingual by default**: every string exists in `es` and `en`
